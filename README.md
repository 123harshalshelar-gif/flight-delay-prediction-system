# ✈️ Flight Delay Prediction System

## Overview
The Flight Delay Prediction System is a Machine Learning project that predicts whether a flight is likely to be delayed based on historical flight data. The model is trained using Python and Scikit-learn and deployed as an interactive web application using Streamlit.

## Features
- Predict flight delays in real time
- User-friendly Streamlit web interface
- Data preprocessing and cleaning
- Machine Learning model training and evaluation
- Interactive deployment on Streamlit Cloud

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Joblib

## Dataset Features
The model uses the following flight-related features:

- Month
- Day
- Day Of Week
- Airline
- Origin Airport
- Destination Airport
- Distance
- Departure Delay
- Scheduled Time
- Air Time
